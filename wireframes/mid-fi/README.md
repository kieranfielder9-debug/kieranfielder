# Mid-Fi Wireframes

Mid-fidelity wireframes for the 5-screen app architecture (Home, Watchtower,
Planning, Allocation, Measurement), built from the diagrammatic wireframe spec
— fixed app shell, T1–T4 typography hierarchy, and the primary UI primitives
(cards, action buttons, inputs, segmented controls).

Live interactive canvas: https://claude.ai/artifact/GWRTWhGC5Gd6XQ5WYBcLmk

The `.dc.html` files here are the artboard source for that canvas, one per
screen, plus `canvas.json` describing their layout on the board.
