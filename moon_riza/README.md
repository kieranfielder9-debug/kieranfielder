# the first man on the moon — riza style 🌙

An AI experiment: the Apollo 11 story retold as a ~52-second edit in the
style of a **Life of Riza** video — and the entire thing is **generated by
code**. No stock footage, no editing software, no cameras. Every frame is
drawn procedurally (Python + Pillow), every sound is synthesized from
scratch (NumPy), and ffmpeg stitches it together.

**Output:** `output/first_man_on_the_moon_riza_style.mp4` (1920×1080 @ 30fps)

## The style ingredients

| Riza trademark | How it's faked in code |
| --- | --- |
| Scrapbook paper + journal pages | Procedural kraft/star-chart paper with fibres, blotches |
| Hand-drawn doodles that wiggle | Every line re-jittered at 7.5 fps ("boil", like redrawn animation) |
| Taped-down polaroids | Illustrated "archival photos" with grain + vignette, washi tape |
| Kinetic typography | Word-by-word easeOutBack "slap-ins", marker highlighter sweeps |
| Typewriter captions | Char-by-char reveal, with a synthesized key-click per letter |
| Snap zooms & camera shake | Affine reframe with per-scene zoom/shake envelopes |
| Film look | Animated grain, dust, scratches, vignette, warm cast, light leaks |
| Lo-fi soundtrack | Synthesized chord pad, 75bpm dusty beat, vinyl crackle |
| NASA radio vibe | Quindar beeps (2475 Hz), static beds, alarm buzzes, launch rumble |

## Story beats

1. **Title** — "the day we left EARTH", July 16, 1969 stamp
2. **Countdown + launch** — Saturn V doodle, 7.5M lbs of thrust
3. **The map** — 238,855 miles of dashed-line trajectory
4. **"four days later..."**
5. **The descent** — 1202 alarm, fuel gauge draining, "THE EAGLE HAS LANDED"
6. **The step** — ghostly CRT broadcast, 600M people watching, the quote
7. **Montage** — the footprint, the $5.50 flag, Buzz's visor portrait
8. **Outro** — the scrapbook wall. "we went to the moon. and it was beautiful."

## Re-render it

```bash
pip install pillow numpy imageio-ffmpeg
python render.py            # full 1080p30 render (~6 min)
python render.py --draft    # fast 540p15 pass
python render.py --stills   # dump keyframes + contact sheets
```

## Files

- `config.py` — the master timeline (scene times, captions, audio cue times)
- `fx.py` — paper, wobbly ink, typography, polaroids, film-look post
- `scenes.py` — the eight scenes + all illustrated "photos" and sprites
- `audio.py` — the synthesized soundtrack, locked to the same timeline
- `render.py` — frames → ffmpeg, plus stills/draft modes
